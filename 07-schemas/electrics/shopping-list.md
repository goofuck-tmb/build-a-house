## 4. Провода внутри щита (ПуГВ, гибкий)

| Сечение | Цвет | Длина | Для чего |
|---|---|---|---|
| [ ] 10 мм² | синий | 1 м | перемычка расщепления PE → N автомата |
| [ ] 6 мм² | коричневый L1 | 3 м | S204 → кросс → УЗИП/реле → дифы → гребёнка |
| [ ] 6 мм² | чёрный L2 | 3 м | то же |
| [ ] 6 мм² | серый L3 | 3 м | то же |
| [ ] 6 мм² | синий N | 3 м | S204 → кросс → УЗИП/дифы; ДИФ-103 → шина N групп |
| [ ] 2,5 мм² | коричневый | 2 м | розетки Finder ×3 |
| [ ] 2,5 мм² | синий | 2 м | то же |
| [ ] 2,5 мм² | жёлто-зелёный | 2 м | то же |
| [ ] 1,5 мм² | коричневый | 2 м | термостат → нагреватель |
| [ ] 1,5 мм² | синий | 3 м | нагреватель + нули трёх реле |
| [ ] 1,5 мм² | жёлто-зелёный | 1 м | нагреватель |

Кабели на группы (ВВГ 3×2,5 / 3×1,5 до ворот, беседки, света, камер, наружной розетки) считаются по трассам отдельно.
