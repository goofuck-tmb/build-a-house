## 4. Провода внутри щита (ПуГВ, гибкий)

| Сечение | Цвет | Длина | Для чего |
|---|---|---|---|
| [x] 10 мм² | жёлто-зелёный | **есть 5 м** | контур → шина PE (по месту, 2–3 м) + шина PE → болт стойки (0,5 м) + УЗИП → шина PE (0,3 м) ≈ 4 м. Замерь трассу от полосы контура до щита: если больше 3,5 м, докупи ещё 5 м |

| [x] 6 мм² | **белый** L3 | 3 м | то же |
| [x] 6 мм² | синий N | 3 м | S204 → кросс → УЗИП/дифы; ДИФ-103 → шина N групп |
| [x] 2,5 мм² | красный, чёрный, белый | по 1 м | розетки Finder ×3: каждая на своей фазе, цвет провода по фазе |
| [x] 2,5 мм² | синий | 2 м | то же |
| [x] 2,5 мм² | жёлто-зелёный | 2 м | то же |
| [x] 1,5 мм² | чёрный (L2) | 2 м | термостат → нагреватель (линия «обогрев» на L2) |
| [x] 1,5 мм² | синий | 3 м | нагреватель + нули трёх реле |
| [x] 1,5 мм² | жёлто-зелёный | 1 м | нагреватель |

**Цвета фаз в этом щите: L1 красный, L2 чёрный, L3 белый** (коричневого и серого в магазинах нет, ГОСТ допускает любые цвета кроме синего и жёлто-зелёного). N только синий, PE только жёлто-зелёный. На концы фазных проводов бирки L1/L2/L3.

Кабели на группы (ВВГ 3×2,5 / 3×1,5 до ворот, беседки, света, камер, наружной розетки) считаются по трассам отдельно.
